# Nauat Мұра 2.0

Қазалы өңірінің тарихы мен дастархан мәдениетін танытатын premium heritage restaurant сайты.

## Іске қосу

```powershell
scripts\dev.cmd
```

Сайт: http://127.0.0.1:3000

## Production дайындау

1. `.env.example` файлын `.env.local` ретінде көшіріңіз.
2. `ADMIN_USER` және `ADMIN_PASSWORD` мәндерін міндетті түрде өзгертіңіз.
3. `NEXT_PUBLIC_SITE_URL` мәнін нақты доменге қойыңыз.
4. Build тексеріңіз:

```powershell
pnpm build
```

5. Production режимінде іске қосу:

```powershell
scripts\start-production.cmd
```

## Әкімші

Әкімші панелі: `/admin`

Қорғаныс: браузер Basic Auth сұрайды. Әдепкі мәндер тек жергілікті тексеруге арналған:

- логин: `admin`
- құпиясөз: `nauat2026`

Production алдында бұл мәндерді `.env.local` ішінде ауыстыру керек.

Әкімші панель арқылы:

- сайттағы негізгі түстерді өзгертуге болады
- басты бет мәтіндерін өзгертуге болады
- hero суретін жүктеуге болады
- мәзір бөлімін қосуға/өшіруге болады
- мұра бөлімін қосуға/өшіруге болады
- брондау бөлімін қосуға/өшіруге болады
- жаңа қосымша бөлімдер қосуға болады
- қажет емес қосымша бөлімдерді өшіруге болады
- бөлімдердің фото және мәтінін өзгертуге болады
- мәзір тағамдарын қосуға және өңдеуге болады
- тарихи объектілерді қосуға және өңдеуге болады
- QR кодты көруге және жүктеуге болады
- брондау өтінімдерін көруге болады

## Деректер

- Мәзір және мұра объектілері: `src/data/db.json`
- Брондау өтінімдері: `src/data/bookings.json`
- Фото жүктеулер: `public/images/uploads`
- Әр сақтауда `src/data/backups` ішінде backup жасалады.

## Hosting ескертпесі

Бұл нұсқа Supabase қосылса Vercel тегін тарифінде де тұрақты сақтаумен жұмыс істейді. Supabase env жоқ болса, жергілікті JSON fallback қолданылады.

Тегін deploy қадамдары: `FREE_DEPLOY_CHECKLIST.md`

## Келесі production қадамдары

- Hosting аккаунтына кіру
- Нақты домен қосу
- `.env.local` ішінде құпиясөзді ауыстыру
- `NEXT_PUBLIC_SITE_URL` мәнін нақты доменге қою
- QR кодтарды нақты доменмен қайта жүктеу
- Supabase/Firebase/SQLite дерек қоймасына көшу
- Брондауды WhatsApp, Telegram немесе CRM жүйесіне қосу
- Нақты тарихи мәтіндер мен кәсіби фотоларды енгізу
